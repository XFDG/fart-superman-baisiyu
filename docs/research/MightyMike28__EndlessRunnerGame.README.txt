# Endless Runner

A simple 2D endless runner game developed using Phaser and JavaScript.

The player moves between three lanes to avoid incoming obstacles. The game becomes progressively more difficult as the player survives longer.

## Live Demo

Play the game here:

https://mightymike28.github.io/EndlessRunnerGame/

## How to Play

### PC

- Left Arrow / A: Move left
- Right Arrow / D: Move right

### Mobile

- Use the on-screen left and right buttons to move between lanes.

## Game Features

- Three-lane movement system
- Random obstacle spawning
- Controlled spawn management
- Collision detection
- Progressive difficulty scaling
- Score based on survival time
- Game Over and restart system
- Keyboard controls for PC
- Touch controls for mobile
- Responsive portrait layout

## Technology

- Phaser
- JavaScript
- Vite
- HTML5
- CSS

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local address displayed in the terminal.

## Production Build

Create a production build with:

```bash
npm run build
```

The production files will be generated inside the `dist` folder.
