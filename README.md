# 放屁超人白思雨 · 浩然杯大冒险

公开试玩版本 v1.2：手机和电脑都在浏览器中游玩。原创 Canvas 卡通画面，纯 Web Audio 搞怪音效，无第三方游戏运行依赖、外部素材或 CDN。

**[手机 / 电脑直接试玩](https://xfdg.github.io/fart-superman-baisiyu/)**

## v1.2 操作更新

游戏顶部“操作指南”可随时查看；打开时暂停，关闭后恢复原来的游戏状态。

- WASD / 方向键：左右移动、向上跳跃或二段跳、向下穿过悬浮平台或加速下落；地面不会被穿透。
- 1 / 2 / 3 / 4：黄屁 / 绿屁 / 普通臭屁 / 粉色香屁。
- K：放屁攻击，点按单发、长按连发；E：拾取后发射浩然屁力炮。
- 手机：左手左右移动与下落，右手跳跃 / 放屁 / 炮击；点击四色技能卡切换，多指同时操作。

## v1.1 更新

- 主角改成戴圆眼镜的原创白色简笔小狗，穿黄围巾、披红披风。
- 放大界面、技能文字和触控按钮，手机竖屏技能改成两列。
- 黄、绿、臭、粉四色屁采用更鲜艳颜色、粗轮廓、拖尾和命中特效。
- 增加轻松 / 标准 / 挑战三种难度，最佳成绩按难度分别记录。
- BOSS 前发光台可拾取 **浩然屁力炮**，按 E 或长按“炮击”发射爆炸炮弹。

## 玩法

穿过豆豆草原、香香云谷、臭臭王国，打败臭臭大王，到终点领取 **浩然杯**。沿途吃豆回复屁力，小旗子保存复活位置。生命耗尽可重开，最佳成绩保存在当前浏览器。

| 技能 | 效果 |
| --- | --- |
| 黄屁 | 冲击波，高伤害并击退，命中时可波及附近敌人 |
| 绿屁 | 留下持续臭雾，造成伤害并减速 |
| 普通臭屁 | 消耗较低、快速连发 |
| 粉色香屁 | 净化攻击；未满血时恢复一颗心，回血冷却约 5 秒 |
| 暴击：大便粒 | 攻击概率额外喷出四颗卡通大便粒，连续四次攻击保底暴击 |

掉进坑会扣一颗心并回到最近旗子；被击中后短暂无敌。支持二段跳、按住攻击、自动回气、暂停与音效开关。切到其他窗口或后台会自动暂停。

## 操作

| 操作 | 电脑 | 手机或鼠标 |
| --- | --- | --- |
| 左右移动 | A / D，或 ← / → | 左手长按左右按钮 |
| 跳跃 / 二段跳 | W / ↑（也可用空格） | 右手点击跳跃；空中再点一次 |
| 下落 | S / ↓ | 点击下落穿过悬浮平台；长按在空中加速下降 |
| 放屁 | K：点按单发 / 长按连发 | 右手点按或长按放屁 |
| 浩然屁力炮 | 拾取后长按 E | 拾取后长按炮击按钮 |
| 选择技能 | 1 / 2 / 3 / 4 | 点击四种屁按钮 |
| 暂停 / 继续 | P 或 Esc | 点击顶部暂停按钮 |
| 操作指南 | 点击顶部操作指南；Esc 关闭 | 点击顶部操作指南；点击关闭返回 |

音效在首次点击“出发”后解锁。手机支持多指同时移动、跳跃和攻击，横屏布局提供右侧操作面板。

## 本地运行

需要 Node.js 20 或更新版本，不需要 npm install。

```sh
npm run dev
```

电脑打开 http://localhost:4173 。手机与电脑连接同一个 Wi-Fi，访问启动日志中的局域网地址，必要时允许系统防火墙访问该端口。WSL 或虚拟机环境需以实际可访问的主机局域网地址为准。

也可使用任意静态 HTTP 服务器；ES modules 不适合直接双击 index.html 以 file:// 打开。

```sh
npm run check
```

## 网页部署

这是静态网页，部署 index.html、style.css、favicon.svg、src/ 即可，无后端。所有资源使用相对路径，支持 GitHub Pages 仓库子路径。

用户已授权公开发布。仓库使用 GitHub Pages 从 main 分支根目录发布；公开试玩地址：https://xfdg.github.io/fart-superman-baisiyu/ 。

## 难度与武器

| 难度 | 生命 | BOSS 生命 | 回气 / 秒 | BOSS 攻击 |
| --- | ---: | ---: | ---: | --- |
| 轻松 | 7 | 290 | 19 | 慢速单发 |
| 标准 | 5 | 430 | 13 | 标准单发 |
| 挑战 | 3 | 680 | 10 | 高速三连弹，得分 ×1.4 |

难度在开始或结算菜单选择，当前局不能中途切换。浩然屁力炮位于大王前的发光台，每发消耗 18 点屁力，直接命中造成 110 伤害并爆炸波及附近敌人，冷却按难度为 1.6 / 1.9 / 2.2 秒。武器拾取后随本局保留，失败重开需要重新拾取。

最佳成绩和静音设置仅保存在当前浏览器，不包含账号或云排行榜。
